# سرداب الألفي — منصة الرعب والحقائق

منصة ويب كاملة: تسجيل بالإيميل ورقم الموبايل مع أكواد تأكيد، رفع فيديوهات، وقسم أخبار/بوستات، بتصميم أزرق فاتح / أزرق غامق / أبيض.

## التشغيل محليًا

```bash
npm install
npm start          # يشتغل على http://localhost:3000
```

- أول حساب يتسجل يبقى **أدمن** تلقائيًا (تقدر كمان تحدد إيميلات الأدمن بمتغير `ADMIN_EMAILS=mail1,mail2`).
- وضع التجربة: أكواد التأكيد بتظهر على الشاشة (لأن خدمات الإرسال لسه مش متوصلة). لإيقاف ده: `DEMO_CODES=0`.

## أوامر مهمة

| متغير بيئة | الوظيفة | الافتراضي |
|---|---|---|
| `PORT` | بورت السيرفر | `3000` |
| `ADMIN_EMAILS` | إيميلات تاخد صلاحية أدمن عند التسجيل | فاضي (أول مسجل = أدمن) |
| `DEMO_CODES` | `1` يعرض الأكواد على الشاشة، `0` يخفيها | `1` |

## البنية

- `server.js` — السيرفر كله (Express + SQLite): حسابات، تأكيد، جلسات، فيديوهات (رفع + تشغيل مع دعم Range)، بوستات، لوحة تحكم.
- `public/style.css` — التصميم كله.
- `uploads/` — ملفات الفيديو المرفوعة. `data/` — قاعدة البيانات SQLite.

## قبل النشر الحقيقي (الإنتاج)

1. **إرسال كود الإيميل:** وصّل خدمة SMTP مجانية (مثلاً Brevo — ٣٠٠ إيميل/يوم مجانًا) في دالة `sendEmailCode` في أول `server.js`.
2. **إرسال كود الموبايل (SMS):** دي الحاجة الوحيدة اللي ملهاش بديل مجاني حقيقي: Twilio Verify بحوالي 0.05 دولار لكل عملية تأكيد، أو Firebase Phone Auth (باقة Blaze مدفوعة). البديل المجاني: الاكتفاء بتأكيد الإيميل وحفظ رقم الموبايل كبيانات فقط.
3. **الاستضافة:** شوف خيارات النشر في التقرير المرافق (Oracle Cloud المجانية الدائمة، أو Render المجاني مع تعديلات التخزين، أو VPS صغير).
4. غيّر `DEMO_CODES=0` بعد توصيل خدمتي الإرسال.
